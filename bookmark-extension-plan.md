## Overview

This product is a cross-browser AI bookmark extension for Chrome, Edge, and other Chromium-based browsers that:

- imports and organizes bookmarks,
- makes them searchable and easier to rediscover,
- uses AI to auto-group and label them,
- surfaces useful opportunities from the web,
- optionally monetizes through affiliate-linked recommendations.

The goal is to improve the browser experience by helping users manage long bookmark lists, quickly find saved pages, and discover related useful opportunities tied to their interests.

---

## Core Product Idea

### Strong parts of the concept

- Bookmark sorting
- AI categorization
- Smart lists
- Fast search
- Browser improvement and discovery layer

### Risky part of the concept

The idea of scanning the internet broadly for all kinds of opportunities such as:

- events
- discounts
- ticket purchases
- investments
- movies
- books

is powerful, but risky if added too early.

### Why that part is risky

- It is too broad for a first product.
- It is hard to do well without high-quality data sources.
- Some areas, especially investments, introduce trust and compliance concerns.
- Affiliate-heavy experiences can feel spammy if user value is not clearly stronger than the monetization.

### Recommended product direction

Start with a focused bookmark intelligence product first, then add opportunity scanning as a second layer.

## Better MVP

Build version 1 around these features:

### 1. Bookmark import and sync

- Read bookmarks from Chrome, Edge, and other Chromium browsers
- Import existing bookmark folders
- Detect duplicates
- Detect dead links
- Detect near-duplicates

### 2. AI auto-organization

- Auto-tag bookmarks
- Auto-generate categories
- Create smart folders such as:
  - Work
  - Shopping
  - Travel
  - Movies
  - Books
  - Learning
  - Tools
  - Investment Research
  - Events
- Allow one bookmark to belong to multiple smart lists

### 3. Search and retrieval

- Instant search bar
- Search by title, URL, keyword, tag, and topic
- Natural language search such as:
  - "find the article about cheap flights"
  - "show me those saved movie review sites"
  - "where is that investment page I bookmarked last month?"
- Filters for:
  - recently saved
  - most visited
  - never revisited
  - broken links
  - shopping or booking links
  - content by topic

### 4. AI summaries

- Generate a one-line summary for each bookmark
- Extract the key topic
- Estimate page type such as:
  - article
  - product
  - ticket or event
  - course
  - video
  - tool
  - review
- Optional prompt for "why you saved this"

### 5. Smart bookmark lists

Examples:

- Weekend Movies
- Books to Buy
- Tech Deals
- Events Near Me
- Trip Planning
- Business Ideas
- Research for Later

These lists can be:

- auto-generated by AI
- editable by the user
- exportable and shareable

### 6. Cleanup tools

Very useful practical features:

- Duplicate bookmark cleaner
- Empty folder cleaner
- Broken link checker
- Outdated content detector
- Suggestions when many pages are about the same thing
- Archive old bookmarks

That alone is already a useful product.

## Second-Layer Monetization Features

Instead of trying to scan everything on the internet, use targeted opportunity modules.

### Good monetizable modules

#### 1. Shopping and deals
- Detect product bookmarks
- Compare prices
- Show discounts
- Add affiliate links to retailers

#### 2. Books
- Detect book-related pages
- Suggest retailers, reviews, and bestseller lists
- Add affiliate links to bookstores

#### 3. Movies and shows
- Detect entertainment bookmarks
- Suggest trailers, ratings, and streaming availability
- Add affiliate links where appropriate

#### 4. Events and tickets
- Detect artist, venue, and event pages
- Alert users to ticket releases or nearby related events
- Add affiliate or partner links to ticket platforms

#### 5. Travel
- Detect destination, hotel, and flight bookmarks
- Build trip lists
- Alert for price drops or related deals
- Add affiliate links to travel platforms

#### 6. Courses and learning
- Detect educational bookmarks
- Organize into learning paths
- Suggest related courses or books
- Add affiliate links to course platforms

### Investments recommendation

Do **not** put investments in version 1.

Reasons:

- Users can lose trust very quickly.
- Recommendations can be interpreted as financial advice.
- The quality bar is much higher.
- Affiliate links mixed with investment opportunities creates a trust problem.

If investments are included later, frame it narrowly as:

- **investment research bookmarks organization**

and not as:

- **investment opportunities scanning**

## Useful Extra Features Worth Adding

These additions would make the extension much more useful in day-to-day browsing.

### 1. Universal bookmark command bar
A quick launcher that lets users:
- search bookmarks
- open multiple results
- add tags
- move items to folders
- create lists

### 2. Save-now, organize-later flow
A one-click save button that lets users save quickly and let AI sort everything later.

### 3. Read-later mode
Turn selected bookmarks into a reading queue.

### 4. Project-based collections
Examples:
- Start a business
- Plan wedding
- Japan trip
- Home office setup

This is stronger than plain folders because it matches how people actually plan things online.

### 5. Re-discovery feed
A homepage panel that shows:
- bookmarks not opened in 90 days
- trending items related to saved links
- incomplete research trails
- pages worth revisiting

### 6. Cross-bookmark insights
Examples:
- You have 26 saved AI tools pages
- Most of your shopping bookmarks are laptops and cameras
- These 8 pages could be merged into one list

### 7. Page relationship mapping
Show bookmarks by cluster or topic map instead of only by folders.

### 8. Smart alerts
- price drops
- event deadlines
- ticket release dates
- domain unavailable notices
- significant page changes

### 9. Bookmark enrichment
Automatically add:
- thumbnail
- favicon
- category
- summary
- last checked date
- status

### 10. Export and sharing
- export smart lists
- share a collection with someone
- public and private list pages
- copy as Markdown or CSV

## Practical Technical Plan

### Browser support first
For Chrome and Edge first.

### Recommended extension architecture
- Manifest V3 extension
- bookmarks API
- storage API
- tabs API
- contextMenus API
- optional history API
- optional notifications API

### Core stack
- Extension frontend: HTML, CSS, JavaScript or React
- Local search index: MiniSearch or Fuse.js
- AI layer for:
  - bookmark classification
  - tag generation
  - summaries
  - smart collection building
- Optional backend for:
  - sync across browsers
  - affiliate, deals, and event feeds
  - account features
  - alerts processing

## Important Privacy Choice

This decision should be made early.

### Option 1: Local-first
- Bookmarks processed on device where possible
- Better privacy and trust
- Stronger adoption potential

### Option 2: Cloud-enhanced
- Richer AI and sync features
- Easier monetization and alerts
- More privacy concerns

### Recommended approach
**Local-first organization, cloud only for optional enrichment and alerts.**

Bookmark data is personal, so privacy will matter a lot for adoption.

## Clear Product Definition

**Linkwise** is an AI-powered browser extension that transforms messy bookmarks into searchable, organized, intelligent collections. It automatically scans a user’s saved bookmarks, groups them into meaningful lists, adds summaries and tags, detects duplicates and broken links, and helps users quickly rediscover useful pages. It also offers optional discovery modules for deals, events, books, movies, travel, and other relevant opportunities tied to the user’s saved interests, with monetization through affiliate partnerships.
